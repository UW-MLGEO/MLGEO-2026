# Clouds Team Folder

This folder contains materials for the Clouds team project.  
It includes code, data, documentation, and supporting files related to our analysis and workflows.

---

## Organization

Project materials are organized into subfolders by assignment or purpose.  
Each assignment folder is self-contained and includes its own documentation and outputs.

---

## Directory Structure

- **04.WashingtonFloodAnalysis/**  
  Assignment folder containing analysis notebooks, outputs, and documentation related to the December

- **README.md**  
  Overview of the Clouds team folder and team members.
