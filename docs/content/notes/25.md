## Notes

In class, we ran a collaborative in-class activity to collectively construct a set of best practices for using machine learning in the geosciences.

Working in groups of three, students contributed to shared documents covering different aspects of the ML workflow. Each group was asked to draw on geosciences-specific examples and to write in their own words. The resulting documents were reviewed together as a class.
